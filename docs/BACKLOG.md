# BobbyBones: backlog

The open work, each item with an ID (`B-nn`), grouped by the owner's priority list of 2026-10-10 ([PLAN.md](PLAN.md)).
Priority: P0 = the run in progress depends on it, P1 = needed for the owner's list, P2 = needed for good play, P3 =
later. Status says where an item stands and since when. Results are in the log ([RESULTS.md](RESULTS.md)).

The routine ([README.md](README.md)): a new item gets the next free number (the highest number in this file and in
the closed list, plus one) and goes into the section it serves; an item that is finished, dropped or overtaken moves
with its row to [archive/BACKLOG_closed.md](archive/BACKLOG_closed.md) in the commit that closes it, with the result
that showed it. `python tools/docs_check.py` says if a number is used twice.
